# Assessment 3.2: Linear Data Structures (SANCHEZ)

This repository contains the dynamic Python programs for each of the linear data structures implemented using the last name **SANCHEZ**, as required by Assessment 3.2:

1. `array_sanchez.py` - Array implementation
2. `linked_list_sanchez.py` - Linked List implementation (Insert at tail, delete from head)
3. `stack_sanchez.py` - Stack implementation (LIFO)
4. `queue_sanchez.py` - Queue implementation (FIFO)

## How to Run in PyCharm
1. Open PyCharm and create a new project folder named `linear_data_structures_sanchez`.
2. Place all `.py` files into this folder.
3. Run each script individually to see the insertion and deletion steps.
